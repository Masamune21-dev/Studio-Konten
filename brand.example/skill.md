# Aturan khusus brand CONTOH FIBER untuk skill video-tiktok

Contoh. Salin folder `brand.example/` ke `brand/` lalu tulis aturan brand kamu di sini. Skill `video-tiktok` menyuruh agen membaca file ini sebelum mulai; isinya menambah (dan kalau bertentangan, menang atas) aturan umum di `skill/video-tiktok/SKILL.md`.

- Karakter: `bayu` (teknisi lapangan, suara Puck), `sari` (CS, Leda), `raka` (admin jaringan, Charon), `dimas` (pelanggan, Fenrir). Nama file gambar: `img/<bayu|sari|raka|dimas>-<pose>.png`.
- Akun resmi: belum ada (isi `social` di `brand.mjs`); jangan mengarang akun di ajakan follow.
- Fakta brand hanya dari profil brand (Pengaturan › Profil brand, awalnya `brand/profile.md`).
